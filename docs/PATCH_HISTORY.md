# Historical AION packages

`patches/release_archives/` stores downloadable ZIP build artifacts created during iterative AION development. They are **historical**, not an ordered installer chain. Their included READMEs and code may be obsolete or superseded by current root source.

Current source snapshot includes: V5 simulator, TradingView gateway, read-only mobile AION, official logo, research suite, integrated original v0.2 backtesting engine, synthetic paper demo (legacy), SnapTrade connection/preflight experiments (archived), Alpaca Paper options worker, chart panel and the recent historical-bars HTTP 400 patch.

Do not use old Webull preflight scripts to place orders. Active auto execution is paper-only and separate from any Webull/SnapTrade integration. Never commit `.env`, SQLite databases or trade logs.
